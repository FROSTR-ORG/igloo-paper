Review & Generate Section
Irreversible rotation checkpoint — single warning block, per-share distribution note, and one destructive primary action. No package passwords on this step.
Review & Generate
This is the irreversible step in keyset rotation. Confirm the source set, then generate fresh device shares for the same group public key. Package passwords are assigned later on the Distribute Shares step.
Before generating fresh shares
This will reconstruct the existing signing key from threshold bfshare sources, split it into fresh shares for the same group public key, replace the current local source profile, and prepare remote bfonboard packages that other devices must adopt.
Use a single warning block here. Do not use a checklist or checkbox-style review pattern.
Distribution happens per share
You will create each remote bfonboard package on the next step and choose its password there.
